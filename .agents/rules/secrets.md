# 凭证

## 1、凭证和个人标识不写进源码、日志和上报

为什么：写进仓库或打进日志的密钥和证件号，会跟着代码和监控离开原来的边界。

```ts
// ✅ 日志只留订单号
logger.error('pay failed', { orderId });
// ❌ 整段请求体打进日志，里面有证件号
logger.error('pay failed', { idCard: body.idCard });
```

边界：把用户输入拼进 HTML 或脚本，由工具报错。这条看凭证和证件号出现在源码、日志还是上报里。有没有越权要对照授权，不在这份凭证里判。
